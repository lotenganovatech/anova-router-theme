Satu tema, empat jalur untuk header dan footer

Setiap kali halaman dibuka, Anova Router memeriksa sumber header dan footer satu per satu. Sumber pertama yang punya template untuk halaman itu yang dipakai, jadi Anda tidak perlu mengedit file tema.

  1. Anova Canvas

    Theme Builder Canvas dengan aturan tampil per halaman. Header dan footer dicetak langsung lewat tema, tanpa output buffering, sehingga lebih bersih.

  2. Elementor Pro

    Semua lokasi inti Theme Builder Elementor Pro sudah didaftarkan. Header, footer, single, dan archive dari Elementor langsung dipakai.

  3. Builder lain

    Hubungkan builder apa pun lewat filter anova_router/do_location. Cukup cetak header Anda dan kembalikan true.

  4. Bawaan tema

    Header dan footer sederhana dengan logo, menu, dan hak cipta. Bisa dimatikan di Tampilan → Sesuaikan → Anova Router bila tidak diperlukan.

Konten halaman tetap milik builder Anda: Elementor, Gutenberg, Anova Canvas, atau builder lain. Tema hanya menyediakan wadah yang bersih.

Semua yang dibutuhkan builder, tidak lebih

Anova Router sengaja hampir kosong, mirip Hello Elementor. Yang ada di dalamnya adalah hal-hal yang memang dipakai saat membangun situs dengan page builder.

Ringan sejak awal

CSS tema sekitar 5 KB. Skrip menu HP hanya dimuat bila menu utama dan header bawaan dipakai, skrip balasan komentar hanya di halaman yang membutuhkannya.

Tiga tata letak halaman

Full selebar layar, Boxed dengan kotak berlebar tetap, atau Custom dengan lebar maksimum pilihan Anda. Lebar aktif ikut dibagikan ke Anova Canvas.

Template kanvas kosong

Template "Kanvas kosong" tanpa header, footer, dan judul untuk landing page, serta "Lebar penuh" dengan header dan footer tetap tampil.

Atur dari Customizer

Header dan footer bawaan, judul halaman, muat atau matikan CSS tema, warna aksen, dan teks footer dengan token {year} dan {site}.

Siap untuk WooCommerce

Dukungan WooCommerce dideklarasikan dan halaman toko dibungkus wadah yang rapi, jadi toko online tidak berantakan sejak awal.

Ramah Gutenberg

Gaya editor, gaya blok, align wide dan full, serta embed responsif. Blok terlihat sama di editor dan di halaman.

Dua bahasa

Teks tema, deskripsi di Tampilan → Tema, notifikasi plugin, bahkan gambar tema mengikuti bahasa WordPress. Bahasa Indonesia dan Inggris sudah tersedia.

Aksesibel

Tautan langsung ke konten, label navigasi yang jelas, dan menu HP yang bisa ditutup dengan tombol Escape.

Pilih lebar halaman, bukan menulis CSS

Tata letak berlaku untuk seluruh halaman: header, konten, dan footer. Body mendapat kelas ar-layout-* sehingga mudah disesuaikan.

Untuk developer

Setiap keputusan tema bisa diubah lewat filter, tanpa child theme untuk hal-hal kecil.

  • anova_router_location( 'header' ) mencetak lokasi lewat builder, true bila berhasil
  • anova_router/show_default_header, /show_default_footer, /show_page_title
  • anova_router_layout() dan filter anova_router/layout
  • anova_router_container_width() dan anova_router/content_width
  • anova_router/full_canvas_width untuk lebar Canvas di tata letak Full
  • add_theme_support( 'anova-canvas' ) sudah dideklarasikan
// Pakai header dari builder lain
add_filter( 'anova_router/do_location', function ( $handled, $location ) {
    if ( $handled || 'header' !== $location ) {
        return $handled;
    }
    echo do_shortcode( '[header_builder_saya]' );
    return true;
}, 10, 2 );

Kembalikan true agar tema tidak mencetak header bawaan.

Mulai dalam empat langkah

Tidak ada wizard panjang. Pasang, aktifkan, lalu langsung bangun halaman di builder Anda.

  1. Pasang tema

    Tampilan → Tema → Tambah Baru → Unggah Tema, pilih file anova-router.zip.

  2. Aktifkan

    Klik Aktifkan. Situs langsung memakai header dan footer bawaan yang rapi.

  3. Pasang Anova Canvas

    Ikuti tombol pada pemberitahuan di Dasbor untuk memasang atau mengaktifkan plugin pendamping.

  4. Atur tampilan

    Buka Tampilan → Sesuaikan → Anova Router untuk tata letak, warna aksen, dan teks footer.

Pertanyaan yang sering muncul

Apakah Anova Router bisa dipakai tanpa Anova Canvas?

Bisa. Tema tetap berjalan dengan header dan footer bawaan, Elementor Pro, atau builder lain. Anova Canvas diminta agar integrasi builder dan Theme Builder bawaan Anova Router aktif.

Saya memakai Elementor gratis. Apakah cocok?

Cocok. Konten halaman dibuat dengan Elementor seperti biasa, dan template "Kanvas kosong" atau "Lebar penuh" membuat halaman benar-benar selebar layar. Theme Builder untuk header dan footer membutuhkan Elementor Pro atau Anova Canvas.

Apakah perlu Loteng Kit?

Tidak. Loteng Kit bersifat opsional dan tidak dibutuhkan oleh Anova Router.

Bagaimana kalau semua desain saya buat di builder?

Matikan "Muat CSS tema" di Customizer. Tema tidak memuat CSS sama sekali dan seluruh tampilan diatur builder Anda.

Apakah tampilan situs lama berubah setelah memperbarui ke versi terbaru?

Tidak. Tata letak bawaan adalah Custom 1200 px yang sama dengan versi sebelumnya, dan lebar kontainer lama otomatis dipakai bila belum ada pengaturan baru.

Bahasa apa saja yang didukung?

Bahasa Indonesia dan Inggris sudah tersedia dan dipilih otomatis sesuai bahasa WordPress. Tema siap diterjemahkan ke bahasa lain lewat file anova-router.pot.
